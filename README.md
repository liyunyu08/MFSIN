# Multi-Scale-Feature-Selection-and-Interaction-Network

## :heavy_check_mark: Requirements
* Ubuntu 16.04
* Python 3.7
* [CUDA 12.1](https://developer.nvidia.com/cuda-toolkit)
* [PyTorch 1.12.0](https://pytorch.org)
